# 📝 기사 프로젝트 노트

기사 프로젝트 하나를 한 페이지에서 정리하는 노트입니다. 설치나 빌드 없이 HTML 파일 하나로 동작하며, 노션·메모 앱처럼 가볍게 읽히도록 만들었습니다. 휴대폰 화면에서도 보기 편합니다.

## 구성

| 칸 | 설명 |
| --- | --- |
| 프로젝트 한 줄 | 프로젝트를 한 줄로 적는 칸 (클릭해서 수정) |
| 주제 | 대주제 `경제` |
| 할 일 체크리스트 | 5개 항목, 완료 개수 표시 (`0 / 5`) |
| 날짜별 기록 | 11/18부터 하루 한 줄씩, 버튼으로 다음 날짜 추가 |

개인정보(전화번호, 주소 등)를 받는 칸은 없습니다.

## 사용법

1. `project-note.html` 파일을 내려받습니다.
2. 브라우저에서 파일을 엽니다. (더블클릭)
3. 각 칸을 눌러 바로 입력합니다. 체크박스로 할 일을 완료 처리합니다.
4. 새 날짜의 기록이 필요하면 하단의 **+ 다음 날짜 추가**를 누릅니다.

### GitHub Pages로 열기 (선택)

저장소 **Settings → Pages**에서 배포 브랜치를 지정하면 웹 주소로 열 수 있습니다. 파일 이름을 `index.html`로 바꾸면 주소 뒤에 파일명을 붙이지 않아도 됩니다.

## 저장 방식

입력한 내용은 사용 중인 브라우저의 `localStorage`에 저장됩니다.

- 같은 브라우저에서 다시 열면 내용이 유지됩니다.
- 서버로 전송되지 않습니다.
- 다른 기기나 다른 브라우저로는 내용이 옮겨지지 않습니다.
- 브라우저의 사이트 데이터를 지우면 입력한 내용도 사라집니다.

## 수정하기

- 주제 변경: HTML의 `<span class="tag">경제</span>` 부분을 고칩니다.
- 할 일 개수 변경: 스크립트의 `for (var i=0;i<5;i++)` 숫자를 바꿉니다.
- 시작 날짜 변경: 스크립트의 `date:'2026-11-18'` 값을 바꿉니다.
- 색상·글자 크기: `<style>` 상단의 `:root` 변수에서 조정합니다.

저장된 내용이 있는 브라우저에서는 초기값을 바꿔도 이전 저장분이 우선 표시됩니다. 처음 상태로 보려면 해당 사이트 데이터를 지우세요.
